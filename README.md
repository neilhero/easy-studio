# Lazy Studio

本机影片放映室：看片、逐帧检查、查看剪辑时间线、对照版本，并保存带时间码和截帧的反馈。

这是从 [FEICAI CLUB / ad-storyboarder](https://github.com/feicaiclub/ad-storyboarder) 提取的独立维护版本，以本地实际使用的界面和服务为基线。上游提交为 `ea420370a0881db7a179dbbb16d02f3f121a6492`（2026-10-19，广告分镜师 v1.0）。保留原 MIT 许可证和作者声明。

## 运行

需要 Python 3.10+ 和 FFprobe（随 FFmpeg 安装）。Python 端仅使用标准库，没有 pip 依赖。

```sh
python3 run.py --root '/你的影视项目目录' --port 8788 --open
```

默认只监听 `127.0.0.1`。浏览器打开 `http://127.0.0.1:8788`。停止服务时在终端按 Ctrl+C。

FFprobe 不在 PATH 时：

```sh
FFPROBE_BIN='/工具目录/ffprobe' python3 run.py --root '/你的影视项目目录' --port 8788
```

仓库仅保存程序代码和说明；影片、剧本、素材、反馈放在外部项目目录，不随代码提交。没有影片也可以启动，会显示空状态。缺少 FFprobe 时媒体元数据和帧率可能不准确，逐帧审片前应安装并配置。

## 项目目录约定

```text
影视项目/
├── 需求文档.md
├── 脚本/
│   └── 分段表.md
├── 素材库/
├── 生成/
├── 剪辑/
│   └── 剪辑表.py
├── final/
│   ├── 当前影片.mp4
│   ├── 自审.md
│   └── _旧版_v1/
│       └── 上一版.mp4
└── 反馈/
    ├── 待处理.md
    └── 帧/
```

`final/` 中放已导出的审片文件。旧版按 `_旧版_vN` 放置可做版本对照。同一目录有多个视频时可在文件下拉框切换。

## 审片操作

- 空格：播放或暂停；← / →：逐帧；Shift + ← / →：前后1秒。
- M：暂停并打标记；写一句反馈后回车保存，带时间码和截帧。
- 时间线：查看剪辑段、源区间和入出点；↑ / ↓：上一镜或下一镜。
- 进度页可关联、选用和评审候选，选择具体成片进行版本验收与前后镜对照。

“过审”用于单镜素材是否可用于剪辑；“验收”用于该镜在指定成片版本中的衔接、节奏和声音是否确认可用。详细约定见 [审片与数据格式](REVIEW-WORKFLOW.md)。

## 代码与迭代基线

```text
run.py                     启动入口
studio.py     本机 HTTP 服务、媒体读取、反馈接口
studio.html   单页前端
common.py     项目路径、FFprobe 与辅助函数
UPSTREAM.md                来源记录
REVIEW-WORKFLOW.md         审片与数据格式
```

当前适配：用 `FFPROBE_BIN` 或 PATH 调用 FFprobe，移除个人机器的绝对路径，不依赖剪映 MCP 的 Python 包。播放器、逐帧、反馈、进度和时间线界面沿用上游。

仅对可信的本机项目使用。时间线文件 `剪辑/剪辑表.py` 会作为 Python 执行；不要加载陌生项目中的脚本。服务对 Host/Origin、隐藏路径和项目越界的限制沿用上游。

后续方向：可编辑初剪、后台超分任务和局部生成返修。当前版本仍只展示时间线，不提供剪辑导出。

## v0.2 镜头评审

进度页选择一段，在右栏读取视频列表，把 `生成/` 或 `素材库/` 中的视频关联到该段。一段可有多个候选，同一文件可关联多段。候选可选用、过审、退回或重置待审；退回需填写原因。选用只登记决定，不会自动修改剪辑表或重新导出影片。

在“指定版本验收与连戏”中选择具体成片，核对并确认剪辑表对应关系后，可验收通过、退回修改，或打开“前镜尾 ↔ 本镜头”“本镜尾 ↔ 后镜头”对照。对照按成片时间显示切点附近各1秒，支持首尾帧、逐帧和循环播放。

评审保存在项目的 `反馈/评审记录.json`，原子写入，写入前备份为 `.json.bak`，历史操作保留。素材内容变化后需复核；验收绑定成片内容及该镜与相邻镜头的剪辑、素材、声音和字幕信息。更换成片或相关剪辑后需重新确认并复核，旧记录保留。旧分段表里的“过审/验收”文字不自动升级为已批准记录。

验证：`python3 -m unittest discover -s tests -v`。测试使用独立临时项目，不对真实影片做批准操作。
