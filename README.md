# Lazy Studio

当前版本 **v1.0.0**。页面版本来自 `VERSION`，Git 标签为 `v1.0.0`。

本机影片放映室：看片、逐帧检查、查看剪辑时间线、对照版本，并保存带时间码和截帧的反馈。

这是从 [FEICAI CLUB / ad-storyboarder](https://github.com/feicaiclub/ad-storyboarder) 提取的独立维护版本，以本地实际使用的界面和服务为基线。上游提交为 `ea420370a0881db7a179dbbb16d02f3f121a6492`（2026-10-19，广告分镜师 v1.0）。保留原 MIT 许可证和作者声明。

## 运行

需要 Python 3.10+ 和 FFprobe（随 FFmpeg 安装）。Python 端仅使用标准库，没有 pip 依赖。

```sh
python3 run.py --root '/你的影视项目目录' --port 8788 --open
```

默认只监听 `127.0.0.1`。浏览器打开 `http://127.0.0.1:8788`。停止服务时在终端按 Ctrl+C。

FFprobe 不在 PATH 时：

```sh
FFPROBE_BIN='/工具目录/ffprobe' python3 run.py --root '/你的影视项目目录' --port 8788
```

仓库仅保存程序代码和说明；影片、剧本、素材、反馈放在外部项目目录，不随代码提交。没有影片也可以启动，会显示空状态。缺少 FFprobe 时媒体元数据和帧率可能不准确，逐帧审片前应安装并配置。

## 整集制作（v1.0）

左侧「整集制作」提供仅素材审查、已有素材出初剪、指定镜头返修、整集制作四个模板。一轮支持分段表中的 1–20 镜。选择当前时间线时，授权镜号须与时间线顺序一致。从候选重新选片时可以明确指定范围，缺候选的镜头会等待补齐。

连接本机 Studio MCP 的智能体可以用一句话启动。例如「授权用当前时间线的镜 1 至 10 做这一集，积分上限 0，先做初剪并复查，最后等我验收」。网页支持零积分制作和本地 RIFE。已明确授权的 LibTV 模型、参考、每次报价及返修指令由智能体提交。额度在整集及每镜尝试次数内累计，未知回执保留原请求和预留额度。

「续跑原任务」会认回原审查、导出与生成任务。「按新输入续做」开启新一轮，历史影片与报告可继续查看。换一镜后，复用有效的未变编码片段与审查证据，重新装配成片并检查变动镜头、相邻接缝及新版全片。复查仍需要宿主智能体实际审查，或通过 `STUDIO_REVIEW_COMMAND` 配置真实的审查器。

剪映交付会生成可编辑草稿并显示交接状态。精修后需在剪映原生导出，再回收实际影片并完成全片复查。整集报告记录授权、素材指纹、检查范围、复用和重做、费用及交付谱系。智能体调用示例见 [智能体接口](docs/AGENT-API.md)。

## 剪映精修（v0.9）

1. 在 Studio 点「剪映精修」，选择已保存初剪、带快照的 Studio 成片，或可转换的项目剪辑表。预览显示轨道数量和不支持的效果。
2. 生成可编辑草稿。可在 Studio 保存新的字幕或音量修订。保存并完全退出剪映后，点「发布到剪映」，再从剪映的本地草稿打开。
3. 在剪映内精修并导出 MP4 或 MOV。保存到 Studio 项目目录或启动时指定的 `--import-root`，然后粘贴影片绝对路径并确认所属修订。
4. 对回收版运行「技术质检」，播放成片并填写全片复查。回收版以文件指纹保存，按全片时间码记录，初剪的镜头时间码不会用于剪映回收版。

草稿服务使用独立的 `jianying-local-mcp` Python 环境。启动 Studio 前，将 `STUDIO_JIANYING_PYTHON` 指向装有该工具和 MCP SDK 的 Python 可执行文件。若剪映使用自定义草稿库，设置 `STUDIO_JIANYING_DRAFT_ROOT`。macOS 常驻服务安装时会保留这两个环境变量。

Studio 交接保留源区间、位置、速度、音量、可转换的独立音频和字幕。复杂调色、转场、定格和复杂声音处理会在转换时列出并拦截。剪映界面的编辑保存在原生副本。Studio 记录发布时的文件指纹与修订来源，检测到原生文件变化时会提示到剪映核对。智能体可从 `studio_project` 查询 `finishing.*` 操作。

## 项目目录约定

```text
影视项目/
├── 需求文档.md
├── 脚本/
│   └── 分段表.md
├── 素材库/
├── 生成/
├── 剪辑/
│   └── 剪辑表.py
├── final/
│   ├── 当前影片.mp4
│   ├── 自审.md
│   └── _旧版_v1/
│       └── 上一版.mp4
└── 反馈/
    ├── 待处理.md
    └── 帧/
```

`final/` 中放已导出的审片文件。旧版按 `_旧版_vN` 放置可做版本对照。同一目录有多个视频时可在文件下拉框切换。

## 审片操作

- 空格：播放或暂停；← / →：逐帧；Shift + ← / →：前后1秒。
- M：暂停并打标记；写一句反馈后回车保存，带时间码和截帧。
- 时间线：查看剪辑段、源区间和入出点；↑ / ↓：上一镜或下一镜。
- 进度页可关联、选用和评审候选，选择具体成片进行版本验收与前后镜对照。

“过审”用于单镜素材是否可用于剪辑；“验收”用于该镜在指定成片版本中的衔接、节奏和声音是否确认可用。详细约定见 [审片与数据格式](REVIEW-WORKFLOW.md)。

## 代码与迭代基线

```text
run.py                     启动入口
studio.py     本机 HTTP 服务、媒体读取、反馈接口
studio.html   单页前端
common.py     项目路径、FFprobe 与辅助函数
UPSTREAM.md                来源记录
REVIEW-WORKFLOW.md         审片与数据格式
```

当前适配：用 `FFPROBE_BIN` 或 PATH 调用 FFprobe，移除个人机器的绝对路径，不依赖剪映 MCP 的 Python 包。播放器、逐帧、反馈、进度和时间线界面沿用上游。

仅对可信的本机项目使用。时间线文件 `剪辑/剪辑表.py` 会作为 Python 执行；不要加载陌生项目中的脚本。服务对 Host/Origin、隐藏路径和项目越界的限制沿用上游。

当前 v0.4 提供独立初剪、版本导出与本机批量超分。局部生成返修留待后续。

## v0.2 镜头评审

进度页选择一段，在右栏读取视频列表，把 `生成/` 或 `素材库/` 中的视频关联到该段。一段可有多个候选，同一文件可关联多段。候选可选用、过审、退回或重置待审；退回需填写原因。选用只登记决定，不会自动修改剪辑表或重新导出影片。

在“指定版本验收与连戏”中选择具体成片，核对并确认剪辑表对应关系后，可验收通过、退回修改，或打开“前镜尾 ↔ 本镜头”“本镜尾 ↔ 后镜头”对照。对照按成片时间显示切点附近各1秒，支持首尾帧、逐帧和循环播放。

评审保存在项目的 `反馈/评审记录.json`，原子写入，写入前备份为 `.json.bak`，历史操作保留。素材内容变化后需复核；验收绑定成片内容及该镜与相邻镜头的剪辑、素材、声音和字幕信息。更换成片或相关剪辑后需重新确认并复核，旧记录保留。旧分段表里的“过审/验收”文字不自动升级为已批准记录。

验证：`python3 -m unittest discover -s tests -v`。测试使用独立临时项目，不对真实影片做批准操作。


## v0.3 初剪与返修

看片页点击“初剪编辑 · v0.3”；没有成片时点击“建立初剪”。支持导入基础原剪辑、同步已选候选、添加/替换素材、调整入出点、顺序、原片音量、预览选段、保存、撤销和重做。同步候选以整段素材替换，请重新核对切点。草稿独立保存在 `剪辑/草稿.json`，保留最近50次保存的撤销记录，使用修订号拒绝旧页面覆盖新草稿。

保存后点击“导出新版本”，任务在后台串行执行，页面显示完成镜头数和失败原因。需要 FFmpeg 和 FFprobe；可用 `FFMPEG_BIN`、`FFPROBE_BIN` 配置路径。输出为首镜尺寸（偶数像素）、25fps、H.264/AAC；不同画幅补黑边，静音素材补静音轨；音量倍数0—4。原片不会被覆盖。

导出存为 `final/初剪_v001.mp4`、`初剪_v002.mp4` 等，新版本保留旧版；相邻 `.mp4.json` 保存成片指纹、源素材指纹与冻结的剪辑快照，供播放时间线和版本验收使用，自动确认映射但不会自动批准。草稿修改不影响旧成片验收。任务保存在 `剪辑/导出任务/`；服务重启后将未结束的任务显示为中断，可再次导出。v0.3.1支持取消当前导出及按原任务快照重试；暂不支持分段恢复。

本版导出限视频顺序剪辑与原片音量。含独立音轨、字幕、调色、淡入淡出或定格的旧剪辑不会被静默导入；请保留原流程处理复杂后期。预览播放源素材选段，浏览器音量上限为1；最终增益以导出结果为准。完整初剪需要导出后查看。

按 M 保存反馈时，同时登记到 `反馈/返修问题.json`；原 Markdown 反馈继续保留。点击“返修问题”，可回看原问题，登记修复后的具体成片，再看片确认复核；状态为待处理/已修复/已复核，历史流转保留。旧 Markdown 反馈不自动补录。更换已修复成片内容后提示重新处理。

素材库默认按镜头数字序号升序排列，可切换降序；当前项目的选择保存在浏览器本地。搜索框常显细边框，空输入不显示占位文字。


## v0.3.1 初剪操作完善

- 选段可循环播放；选择预览镜头后，可将播放位置设为入点/出点，或按0.04秒微调切点（25fps导出的时间步长；源视频可变帧率时不承诺逐解码帧精度）。
- 导出中点击“取消导出”，后台停止并回收当前FFmpeg进程，未发布的临时文件清理；已经完成的成片不能取消。
- 失败、取消或服务中断的任务可“按原任务重试”，沿用当时的素材、切点和音量，生成新的版本号；源素材内容变化时拒绝重试，须重新核对草稿。
- 返修问题选择新成片后点击“定位修复镜头”，按稳定镜头ID（含分段表中的段号/节拍对应关系）定位到新镜头的相对时间。镜头缩短时限制在镜尾范围；这是复核起点，不保证对应相同动作。缺少导出快照或镜头歧义时提示手动定位。

验证：22项测试通过，含真实FFmpeg导出、取消进程回收、原任务重试、跨版本定位、HTTP写入保护。浏览器临时项目跑通镜14切点微调、镜20替换、v002导出、问题定位与复核，验证选段循环播放；真实项目影片与评审未作测试性修改。


## v0.4 超分工作台与浅色浮岛界面

素材库点击“超分工作台”，批量选择1—100条原片，设置模型2×/3×与目标高度720/1080/1440/2160p。使用现有Real-ESRGAN ncnn Vulkan、animevideov3模型及FFmpeg；程序不自动下载工具或模型，不调用收费生成服务。

启动前配置 `FFMPEG_BIN`、`FFPROBE_BIN`、`REALESRGAN_BIN`（可执行文件路径）和 `REALESRGAN_MODELS`（模型目录，需有 `realesr-animevideov3-x2.bin/.param` 或x3对应文件；就绪检查以x2为基准）。模型/工具不提交仓库。

任务串行运行，按抽帧→超分→编码并保留原声→完整解码检查执行。面板显示阶段、已处理帧、已用时间、超分阶段剩余时间估算和临时磁盘估算；估算不是承诺值。输出按原片比例缩放至目标高度、偶数宽度，声音转AAC，静音原片保持无声。只处理能解析且帧率元信息一致的素材；不承诺可变帧率的时序保真。

状态保存到 `剪辑/超分任务/`，结果存入 `素材库/Studio超分/`，不会自动入片或获得内容批准。支持排队/运行中取消；服务重启显示中断，点击单文件重试。恢复粒度是文件：完成且源内容、参数、模型和工具指纹一致的有效结果复用；未完成文件重新抽帧推理，不复用其部分帧。当前仅支持单服务进程管理同一项目。

结果点击“原片 / 超分对照”，同步播放、共用时间滑块、按输出帧率步进，按需试听超分原声。指纹变化后拒绝自动对照。浏览器同步受解码调度影响，采用时间误差校正，不作为逐解码帧一致性的证明。

界面保留浅色浮岛方向，默认浅色并保留已有主题偏好。统一标题、留白、卡片、筛选控件、进度表、播放器时间线与弹窗层级；素材库改为响应式镜头卡片网格，支持键盘焦点与减少动画偏好。

验证：26项测试通过，含真实Real-ESRGAN双文件超分（带声与静音）、缓存和指纹、排队与运行中取消、重启中断状态、HTTP写入保护及既有剪辑评审回归。浏览器临时项目已完成双文件批量提交与结果对照，实际项目未作测试性修改。


v0.4.1：素材库分类筛选与相邻工具按钮统一为32px高、1px边框并对齐；镜头卡片固定预览区比例，多候选在同一卡片内缩小排列。已在真实项目浏览器检查单候选/双候选卡片尺寸、分类筛选和排序。


v0.4.2：素材分类使用共用外框的分段控件，内部无独立边框，以浅色底区分选中项。浏览器已检查外框1px、内部0px、整体32px高、与工具按钮对齐和分类切换。


## v0.5 连戏与技术质检

页面右下角常显运行服务的 `Lazy Studio v0.5.0`，版本直接来自 `VERSION` 和 `/api/project`。导航新增“连戏与质检”（窄屏显示“质检”）。

- 参考卡支持人物、服装、道具、场景，选择素材库中的图片，填写名称与说明。编辑参考卡时追加修订，保留历史版本及图片指纹。引用图片是项目文件路径，不另复制图片；图片被覆盖时显示变化提示，旧图恢复需自行保留原文件。
- 镜头要求可逐行填写，关联参考卡时固定其当前版本。人工连戏逐项记录人物服装、道具状态、站位视线、运动方向、光线、动作台词，可标待检查/通过/有问题；发现问题须填写说明。
- 连戏记录绑定具体成片、剪辑邻接上下文、要求和参考指纹。更换成片、相关剪辑、要求或参考后提示复核，旧记录保留。旧项目须先在进度页确认剪辑表与成片的对应关系，自动导出快照可直接使用。入口复用已有前镜尾/本镜头、当前尾/后镜头的视频对照与循环播放。
- 技术质检后台单任务运行，最长30分钟，固定阈值：黑帧≥0.1秒、静帧≥1秒、静音≥0.5秒；记录解码结果、尺寸、帧率、音轨缺失和峰值。峰值达到0dBFS只表示疑点，不等同确认削波。每条疑点可点击时间码打开视频定位。
- 连戏资料保存在 `反馈/连戏资料.json`；质检报告保存在 `反馈/技术质检/`。报告绑定视频指纹，文件变化后标记过期，需重新检查；中断任务显示中断，可手动重新发起。

技术检查没有自动判断人物身份、表演、剧情、口型或台词语义；静帧和静音可能是正常创作设计。当前不提供LUFS测量、自动转写、可配置检测阈值或多人权限。人工连戏“已检查”与素材过审/成片验收独立，不自动批准。

验证：29项测试通过，包括参考修订、旧记录保留、版本隔离、指纹变化失效、真实黑帧/静帧/静音检测、HTTP保护及既有功能。浏览器临时项目验证参考创建、镜头关联、人工检查保存、技术报告、时间码定位与相邻镜对照；真实项目评审未作测试性修改。


## v0.6 智能体入口与统一任务

新增本机MCP stdio代理 `mcp_server.py`，提供 `studio_project` 与 `studio_call`；服务端复用网页同一套业务函数，按项目修订和幂等键处理写入。SQLite保存稳定身份、操作回执和统一任务索引，原JSON/Markdown保留。导航“统一任务”可查看网页和智能体创建的质检、超分、导出状态。

启动时可重复指定 `--import-root '/授权媒体目录'`，不指定时禁止外部导入。令牌和账本保存在项目隐藏的 `.studio/`，禁止网页下载，同项目重复启动会拒绝。MCP代理连接已有服务，不启动第二套执行器；服务重启后的中断任务须显式重试，未知受理结果先协调再决定，不盲目重提。

[智能体接入、操作契约和宿主配置样例](docs/AGENT-API.md)。本版支持2025-11-25/2025-06-18的MCP stdio协议；远程ChatGPT、生成平台、自动审片和剪映接入不在本版范围。当前聊天不会自动获得新注册工具，宿主须另行配置连接。

## macOS常驻运行（v0.6.1）

直接运行run.py依赖当前终端/执行会话。长期使用可安装用户级launchd服务，独立于聊天与终端，登录后启动，进程退出后自动重启；仅监听本机。先确认无任务运行并停止原手动服务，保留所需工具环境变量，再执行：

```sh
python3 service.py install --root '/项目目录' --port 8790 --import-root '/允许导入的目录'
python3 service.py status --root '/项目目录' --port 8790
python3 service.py stop --root '/项目目录' --port 8790
python3 service.py start --root '/项目目录' --port 8790
```

安装仅登记当前项目的用户LaunchAgent，不安装系统级服务；只继承FFmpeg/FFprobe/Real-ESRGAN及Python缓存路径变量。配置位于用户 `Library/LaunchAgents/local.lazy-studio.<项目标识>.plist`，输出及错误日志位于项目 `.studio/logs/service.out.log`、`service.err.log`。同项目服务锁继续生效；安装时遇到手动服务或已加载服务会拒绝覆盖。stop会先检查未结束任务；stop后本次登录不自动重启，start可恢复，保留的安装配置会在下次登录加载。

应用休眠/设备关机期间不保证本机服务响应；恢复登录后由launchd启动。后台程序崩溃可自动重启，但中断任务仍需按v0.6任务状态显式处理，不自动重复执行。

## v0.7.1 跟随当前剪辑检查

- **检查当前剪辑**：沿用已保存草稿中的素材、截取区间、顺序和音量，不重新选片。没有草稿时可读已有基础剪辑表，也可指定已导出的版本。
- **从候选重新初剪**：对勾选镜头重新挑选素材，另存成片建议。原草稿保留；检查完成后点击“采用为当前草稿”才应用，可用初剪编辑的撤销恢复。草稿有其他修改时会拒绝直接覆盖。
- 镜头列表显示正在使用的文件、源入出点及备用数量。保存换片后会自动跟随；检查过程遇到剪辑变化会提示检查新版。
- 有上次完整检查时，未改动镜头和未改变的相邻接缝可沿用结果，改动片段、受影响接缝和新版全片重新检查；勾选可强制复查。旧报告、旧证据和旧成片保留。
- 无改动时直接显示上次结果。指定历史成片时检查该成片，不随草稿变化；沿用旧报告的片段会明确标记。
